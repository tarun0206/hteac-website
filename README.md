# Hindustan Tea Co. — Heritage Since 1973

A cinematic, modern web landing page and interactive media archive for **Hindustan Tea Company**, India's premier tea manufacturer established in 1973.

Built with **pure Vanilla HTML5, CSS3, and JavaScript** (Zero build dependencies).

---

## 🍵 Features

- **Cinematic Heritage Hero**: 1080p ambient background video with cursor glow tracking and invitation lead capture form.
- **Google Sheets Lead Sync**: Real-time serverless lead capture via Google Apps Script Web App.
- **Interactive Media Archive**:
  - Filter by *Zee Hindustan News broadcasts*, *Estates & Harvest*, and *Craft & Packaging*.
  - Fullscreen accessible video & high-resolution photo Lightbox Player.
- **1973 Legacy Story**: Authentic brand history from Sh. B.K. Singh and Mr. M.K. Singh across Darjeeling, Assam, and South India.
- **Direct Concierge**: Office coordinates, phone, WhatsApp direct chat, and official Instagram ([@h.tea.c_](https://www.instagram.com/h.tea.c_/)).

---

## 🚀 Getting Started

Simply open `index.html` in any modern browser, or run a local HTTP server:

```bash
# Python
python -m http.server 3000

# Node
npx serve .
```

Visit `http://localhost:3000/`.
